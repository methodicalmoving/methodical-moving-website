# Workflows

Markdown SOPs that define how to accomplish specific tasks using the WAT framework.

## Structure of a Workflow
Each workflow file should include:
1. **Objective** — What this workflow accomplishes
2. **Inputs** — What's required before starting
3. **Steps** — Ordered list of actions (which tools to run, in what order)
4. **Outputs** — What success looks like and where results go
5. **Edge Cases** — Known failure modes and how to handle them

## Naming
Use snake_case: `scrape_website.md`, `generate_report.md`, `update_sheet.md`
